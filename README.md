# Bincom ICT Python Basic Developer Test

A one-file Python solution that parses weekly colour-wear data, cleans typos, computes statistics, stores results in PostgreSQL, and solves classic programming exercises.

## Overview

This project solves the Bincom ICT basic developer test by turning a messy week of colour-wear records into clean statistics and demonstrating common programming tasks in a single script. Teams can run it out of the box to see frequency analysis, database storage, recursive search, and number conversions in one place.

## Usage

Run the script directly with the embedded sample table:

```bash
python bincom_test.py
```

Or point it at your own saved HTML file:

```bash
python bincom_test.py page.html
```

The output prints colour frequencies and answers to all nine test questions:

```text
Colour frequencies: {'BLUE': 31, 'WHITE': 16, 'GREEN': 10, 'RED': 9, 'ORANGE': 9, 'BROWN': 6, 'PINK': 5, 'YELLOW': 5, 'CREAM': 2, 'ASH': 1, 'BLACK': 1}
Total shirts counted: 95

1. Mean frequency = 8.64 -> mean colour: ORANGE
2. Most worn colour: BLUE (31 times)
3. Median colour: BROWN
4. Variance of frequencies: 68.2314
5. P(red) = 9/95 = 0.0947
```

For database storage, set a `DATABASE_URL` environment variable or use the individual `PGHOST`, `PGPORT`, `PGDATABASE`, `PGUSER`, and `PGPASSWORD` variables. Install the optional dependency first:

```bash
pip install psycopg2-binary
```

On Windows, set environment variables in PowerShell like this:

```powershell
$env:DATABASE_URL="postgresql://user:pass@host/dbname?sslmode=require"
```

On macOS or Linux, add them to your shell profile:

```bash
export DATABASE_URL="postgresql://user:pass@host/dbname?sslmode=require"
```

## Features

- Parses HTML colour tables from a file or embedded sample data
- Corrects common typos in the dataset, such as "BLEW" to "BLUE"
- Calculates mean, median, variance, and most worn colour
- Computes the probability of picking a red shirt at random
- Saves colour frequencies to a PostgreSQL table with conflict handling
- Implements a recursive linear search with an interactive demo
- Generates random 4-bit binary numbers and converts them to decimal
- Returns the sum of the first 50 Fibonacci numbers
